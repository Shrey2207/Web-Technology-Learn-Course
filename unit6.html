1. Introduction to Server-Side Scripting

Server-side scripting is a technique in which programs are executed on a web server instead of the user's browser. It is used to create dynamic web pages and process user requests.

When a user visits a website or submits a form, the browser sends a request to the server. The server processes the request and sends a response back to the browser.

How Server-Side Scripting Works

  1. The user opens a website or submits a form.
  2. The browser sends an HTTP request to the web server.
  3. The web server passes the request to the server-side program.
  4. The program processes the request and may communicate with a database.
  5. The server generates a response, usually HTML or JSON.
  6. The browser receives and displays the response.

Client-Side vs Server-Side Scripting

Client-Side Scripting Server-Side Scripting
Runs in the user's browser. Runs on the web server.
Used for interactive user interfaces. Used for processing data and application logic.
JavaScript is commonly used. PHP, Python, Java and other languages are used.
Code can generally be viewed in the browser. Server-side source code is not sent to the browser.

Uses of Server-Side Scripting

  • User registration and login systems.
  • Processing online forms.
  • Storing and retrieving database information.
  • Creating shopping carts and payment systems.
  • Displaying personalized content.
Remember: PHP code runs on the server. The browser receives the generated output, not the original PHP source code.

2. PHP and Its Features

PHP stands for PHP: Hypertext Preprocessor. It is an open-source, server-side scripting language mainly used for web development.

PHP can be embedded directly into HTML. It allows developers to create dynamic web pages, process forms, manage sessions and communicate with databases.

Features of PHP

  • Open Source: PHP is freely available to use.
  • Server-Side Language: PHP executes on the web server.
  • Easy to Learn: Its syntax is relatively simple for beginners.
  • HTML Integration: PHP code can be written inside HTML documents.
  • Database Support: PHP can connect to databases such as MySQL.
  • Cross-Platform: PHP works on different operating systems.
  • Framework Support: Frameworks such as Laravel and Symfony support PHP development.

Example of PHP Embedded in HTML

<!DOCTYPE html>
<html>
<body>

<h1>Welcome to My Website</h1>

<?php
echo "This message is generated by PHP.";
?>

</body>
</html>

3. Basic Syntax of PHP

PHP code is written between special PHP tags. These tags tell the server where PHP code begins and ends.

PHP Opening and Closing Tags

<?php

echo "Hello World!";

?>
  • <?php starts PHP code.
  • ?> ends the PHP code section.
  • echo displays output.

Semicolon

Most PHP statements end with a semicolon (;). It indicates the end of a statement. 

<?php

echo "Welcome";
echo "PHP Programming";

?>

Comments in PHP

Comments are notes written inside a program. They are ignored during execution and help explain the code. 

<?php

// This is a single-line comment

# This is also a single-line comment

/*
This is a
multi-line comment
*/

echo "Learning PHP";

?>

PHP Case Sensitivity

Variable names in PHP are case-sensitive. For example, $name and $Name are different variables. PHP keywords and function names are generally case-insensitive, but using a consistent lowercase style is recommended.

4. PHP Variables and Data Types

A variable is a named storage location used to hold data. In PHP, every variable begins with the dollar sign ($).

Rules for PHP Variables

  • A variable must start with the $ symbol.
  • The variable name must begin with a letter or underscore.
  • A variable name cannot start with a number.
  • Variable names are case-sensitive.
  • Spaces are not allowed in variable names.

Example

<?php

$name = "Rahul";
$age = 18;
$marks = 85.5;

echo $name;
echo $age;
echo $marks;

?>

Data Types in PHP

A data type specifies the kind of value stored in a variable. Common PHP data types include:

Data Type Description Example
String Stores text. "Hello"
Integer Stores whole numbers. 25
Float Stores decimal numbers. 15.75
Boolean Stores true or false. true
Array Stores multiple values. [10, 20, 30]
NULL Represents a variable with no value. NULL
Object Stores an instance of a class. new Student()

Checking Data Types

<?php

$name = "Amit";
$age = 20;
$marks = 90.5;

var_dump($name);
var_dump($age);
var_dump($marks);

?>

The var_dump() function displays information about a variable, including its data type and value.

5. PHP Operators and Strings

PHP Operators

Operators are symbols used to perform operations on variables and values.

Operator Type Operators Purpose
Arithmetic +, -, *, /, % Perform mathematical operations.
Assignment =, +=, -=, *= Assign values to variables.
Comparison ==, ===, !=, >, < Compare two values.
Logical &&, ||, ! Combine conditions.
Increment / Decrement ++, -- Increase or decrease a value.

Arithmetic Operator Example

<?php

$a = 20;
$b = 10;

echo $a + $b;
echo "<br>";
echo $a - $b;
echo "<br>";
echo $a * $b;
echo "<br>";
echo $a / $b;
echo "<br>";
echo $a % $b;

?>

PHP Strings

A string is a sequence of characters used to store text. PHP supports single-quoted and double-quoted strings. 

<?php

$name = "Amit";

echo 'Welcome to PHP';
echo "<br>";
echo "Hello $name";

?>

Single-quoted strings mostly display their content literally. Double-quoted strings can insert variable values directly into the text.

String Concatenation

The dot (.) operator joins two or more strings together. 

<?php

$first = "Hello";
$second = "World";

$result = $first . " " . $second;

echo $result;

?>

6. PHP Arrays

An array is a variable that can store multiple values under a single name. PHP supports indexed arrays, associative arrays and multidimensional arrays.

A. Indexed Array

An indexed array stores values using numeric indexes. The first index is normally 0. 

<?php

$fruits = array("Apple", "Mango", "Banana");

echo $fruits[0];
echo "<br>";
echo $fruits[1];

?>

B. Associative Array

An associative array stores values using named keys instead of numeric indexes. 

<?php

$student = array(
    "name" => "Rahul",
    "age" => 18,
    "marks" => 85
);

echo $student["name"];
echo "<br>";
echo $student["marks"];

?>

C. Multidimensional Array

A multidimensional array contains one or more arrays inside another array. 

<?php

$students = array(
    array("Rahul", 85),
    array("Amit", 90),
    array("Priya", 95)
);

echo $students[0][0];
echo "<br>";
echo $students[1][1];

?>

Using foreach with Arrays

The foreach loop is used to access each element of an array. 

<?php

$colors = array("Red", "Green", "Blue");

foreach ($colors as $color) {
    echo $color;
    echo "<br>";
}

?>

7. Conditions, Loops and Functions

A. Conditional Statements

Conditional statements allow a program to make decisions based on whether a condition is true or false.

if Statement 
<?php

$age = 18;

if ($age >= 18) {
    echo "You are eligible to vote.";
}

?>
if-else Statement 
<?php

$marks = 35;

if ($marks >= 40) {
    echo "Pass";
} else {
    echo "Fail";
}

?>
if-elseif-else Statement 
<?php

$marks = 85;

if ($marks >= 90) {
    echo "Grade A";
} elseif ($marks >= 75) {
    echo "Grade B";
} else {
    echo "Needs Improvement";
}

?>
switch Statement

A switch statement is used when one expression needs to be compared with several possible values. 

<?php

$day = 2;

switch ($day) {
    case 1:
        echo "Monday";
        break;

    case 2:
        echo "Tuesday";
        break;

    case 3:
        echo "Wednesday";
        break;

    default:
        echo "Invalid Day";
}

?>

B. Loops in PHP

Loops are used to execute a block of code repeatedly while a condition is satisfied or for each item in a collection.

for Loop 
<?php

for ($i = 1; $i <= 5; $i++) {
    echo $i;
    echo "<br>";
}

?>
while Loop 
<?php

$i = 1;

while ($i <= 5) {
    echo $i;
    echo "<br>";
    $i++;
}

?>
do-while Loop 
<?php

$i = 1;

do {
    echo $i;
    echo "<br>";
    $i++;
} while ($i <= 5);

?>
foreach Loop 
<?php

$subjects = array("HTML", "CSS", "PHP");

foreach ($subjects as $subject) {
    echo $subject;
    echo "<br>";
}

?>

C. Functions in PHP

A function is a reusable block of code designed to perform a particular task. Functions help reduce repetition and make programs easier to maintain.

Creating and Calling a Function 
<?php

function greet() {
    echo "Welcome to PHP";
}

greet();

?>
Function with Parameters 
<?php

function add($a, $b) {
    return $a + $b;
}

echo add(10, 20);

?>

Parameters receive values, and the return statement sends a result back to the place where the function was called.

8. PHP Forms and Form Handling

HTML forms collect information from users. PHP can receive and process the submitted information on the server.

Important Form Methods

GET Method POST Method
Data is generally included in the URL. Data is sent in the request body.
Suitable for searches and retrieving information. Commonly used for form submissions that change or send data.
Data may be visible in browser history and URLs. Data is not normally displayed in the URL.

HTML Form Example

<form method="post" action="welcome.php">

    Name:
    <input type="text" name="username">

    <button type="submit">Submit</button>

</form>

PHP Form Processing

The following PHP code receives the submitted name using the POST method. 

<?php

$name = $_POST['username'] ?? '';

echo "Welcome " . htmlspecialchars($name, ENT_QUOTES, 'UTF-8');

?>

Important PHP Superglobal Variables

  • $_GET: Receives data submitted through the GET method.
  • $_POST: Receives data submitted through the POST method.
  • $_REQUEST: Can contain request data from GET, POST and COOKIE sources, depending on configuration.
  • $_SERVER: Contains information about the server and current request.
Important: Form data should never be trusted automatically. Always validate submitted values on the server.

9. Input Validation and Output Escaping

Input validation checks whether the information entered by a user follows the rules required by an application.

Output escaping converts special characters into a safe form before displaying user-provided content in HTML.

Input Validation

  • Check whether required fields are empty.
  • Check the length of entered text.
  • Check whether values are in the correct format.
  • Reject values that do not follow application rules.

Example of Validation

<?php

$name = trim($_POST['name'] ?? '');

if ($name == "") {
    echo "Please enter your name.";
} else {
    echo "Name accepted.";
}

?>

Output Escaping with htmlspecialchars()

The htmlspecialchars() function converts special HTML characters into their safe HTML representations. It helps prevent user input from being interpreted as HTML. 

<?php

$name = "<script>alert('Hello')</script>";

echo htmlspecialchars(
    $name,
    ENT_QUOTES,
    'UTF-8'
);

?>

Instead of treating the submitted text as HTML code, the browser displays it as text.

Validation and output escaping solve different problems. Validation checks whether input is acceptable, while escaping protects the context where data is displayed.

10. String Processing Functions

PHP provides many built-in functions for working with strings. These functions can be used to search, replace, count, remove spaces and modify text.

Function Purpose Example
strlen() Returns the byte length of a string. strlen("Hello")
trim() Removes whitespace from both ends. trim(" PHP ")
str_replace() Replaces specified text. str_replace("Hi", "Hello", $text)
strtolower() Converts text to lowercase. strtolower("HELLO")
strtoupper() Converts text to uppercase. strtoupper("hello")
str_word_count() Counts words in a string. str_word_count("Hello World")
strpos() Finds the position of text. strpos("Hello", "e")
substr() Extracts part of a string. substr("Hello", 0, 3)

Example of String Functions

<?php

$text = "  Welcome to PHP  ";

echo trim($text);
echo "<br>";

echo strlen(trim($text));
echo "<br>";

echo strtoupper($text);
echo "<br>";

echo str_replace("PHP", "Web Technology", $text);

?>
Unicode note: strlen() counts bytes, not necessarily visible characters. For Unicode text, mb_strlen() can be used when the PHP mbstring extension is enabled.

11. Regular Expressions in PHP

A regular expression, also called regex, is a pattern used to search, match or replace text. PHP uses PCRE (Perl Compatible Regular Expressions) through its preg_* functions.

Uses of Regular Expressions

  • Checking whether text follows a particular pattern.
  • Finding specific words or characters.
  • Validating common input formats.
  • Extracting information from text.
  • Replacing matching parts of a string.

Important Regex Symbols

Symbol Meaning
^ Matches the beginning of a string.
$ Matches the end of a string.
. Matches almost any single character.
* Matches zero or more occurrences.
+ Matches one or more occurrences.
? Makes the preceding item optional.
[abc] Matches any one character from the set.
\d Matches a digit.
\D Matches a non-digit character.
\s Matches whitespace.

Important PHP Regex Functions

  • preg_match(): Checks whether a pattern matches a string.
  • preg_replace(): Replaces text that matches a pattern.
  • preg_match_all(): Finds all matches of a pattern.

Example: Using preg_match()

<?php

$email = "student@example.com";

$pattern = '/^[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}$/i';

if (preg_match($pattern, $email) === 1) {
    echo "Email format is valid.";
} else {
    echo "Invalid email format.";
}

?>

Example: Using preg_replace()

<?php

$phone = "(555) 123-4567";

$result = preg_replace('/\D+/', '', $phone);

echo $result;

?>

The pattern \D+ matches one or more non-digit characters. The preg_replace() function removes those characters by replacing them with an empty string.

Regex can check whether text follows a pattern, but it cannot prove that an email address exists. For email format checking, PHP also provides filter_var() with FILTER_VALIDATE_EMAIL.

12. Introduction to Web Development Frameworks

A web development framework is a collection of reusable tools, libraries and components that help developers build web applications more efficiently.

A PHP framework provides a structured way to develop applications without writing every feature from the beginning.

Why Are Frameworks Used?

  • They reduce repeated coding.
  • They provide organized project structures.
  • They simplify URL routing.
  • They provide tools for database operations.
  • They support form validation and authentication.
  • They make applications easier to maintain and test.

Common Features of PHP Frameworks

  • Routing: Connects website URLs to application code.
  • Templating: Helps generate dynamic HTML pages.
  • Database Tools: Simplifies database access.
  • Validation: Helps check user-submitted data.
  • Security: Provides tools for common security tasks.
  • Testing: Helps developers check application behavior.

13. MVC Architecture

MVC stands for Model-View-Controller. It is a software design pattern used to organize an application into three main components.

1. Model

The Model represents the application's data and business rules. It commonly interacts with the database.

Example: A Student Model may manage student names, marks and records.

2. View

The View is responsible for displaying information to the user. It generally contains the user interface, such as HTML templates.

Example: A student details page displaying the student's name and marks.

3. Controller

The Controller receives a request, coordinates the required operations and decides which response should be returned.

Example: A controller receives a request to display student details, gets the information from the Model and passes it to the View.

Advantages of MVC

  • Separates different responsibilities.
  • Makes code easier to understand.
  • Improves application maintenance.
  • Supports testing and teamwork.
  • Allows changes to one component with less effect on others.
MVC is a common organizational pattern. Different frameworks may implement it in different ways.

15. Laravel Framework Example

Laravel is a PHP framework that helps developers create web applications using organized routes, controllers, views and reusable components.

Step 1: Create a Laravel Project

Laravel requires a supported PHP installation and Composer, which is PHP's dependency manager. 

composer create-project laravel/laravel php-framework-demo

cd php-framework-demo

php artisan serve

Step 2: Create a Route

Open the routes/web.php file and add the following code. 

<?php

use Illuminate\Support\Facades\Route;

Route::get('/hello/{name}', function (string $name) {
    return view('hello', ['name' => $name]);
});

Step 3: Create a View

Create a file named hello.blade.php inside the resources/views folder. 

<!DOCTYPE html>
<html>
<head>
    <title>Laravel Example</title>
</head>

<body>

    <h1>Hello, {{ $name }}!</h1>

    <p>Welcome to Laravel.</p>

</body>
</html>

Step 4: Open the Website

Start the Laravel development server using: 

php artisan serve

Open the URL shown in the terminal and visit: 

http://127.0.0.1:8000/hello/Rahul

The page displays: Hello, Rahul!

This is a Laravel project example. It requires PHP, Composer and the Laravel dependencies to be installed. It cannot run simply by opening this study-guide HTML file.

16. Running PHP Programs

A PHP program must be executed using a PHP interpreter. Opening a PHP file directly in a browser using a file:// address does not execute the PHP code.

Method 1: Using PHP Command Line

  1. Install PHP on your computer.
  2. Create a file named hello.php.
  3. Write your PHP program and save it.
  4. Open the terminal in the file's folder.
  5. Run the following command.
php hello.php

Method 2: Using PHP Development Server

  1. Create a PHP file named hello.php.
  2. Open the terminal in the same folder.
  3. Start the development server.
php -S localhost:8000

Now open the following address in your browser: 

http://localhost:8000/hello.php

The PHP development server processes the file and sends the generated response to the browser.

17. Security and Best Practices

Security is an important part of server-side web development. PHP applications should be designed to protect user information and prevent unauthorized access.

Important Security Practices

  • Validate Input: Check all data submitted by users.
  • Escape Output: Use htmlspecialchars() when displaying untrusted text in HTML.
  • Protect Database Queries: Use prepared statements instead of joining user input directly into SQL queries.
  • Protect Passwords: Use password_hash() to store passwords and password_verify() to check them.
  • Protect Private Information: Never expose database passwords or private source code in public directories.
  • Update Dependencies: Keep PHP, frameworks and libraries updated.
  • Use HTTPS: Protect information transmitted between browsers and servers.

Example: Password Hashing

<?php

$password = "mypassword123";

$hashedPassword = password_hash(
    $password,
    PASSWORD_DEFAULT
);

echo $hashedPassword;

?>

Verifying a Password

<?php

$password = "mypassword123";

$hashedPassword = password_hash(
    $password,
    PASSWORD_DEFAULT
);

if (password_verify($password, $hashedPassword)) {
    echo "Password matched.";
} else {
    echo "Incorrect password.";
}

?>
Never store passwords as plain text. Store secure password hashes and verify submitted passwords using password_verify().
