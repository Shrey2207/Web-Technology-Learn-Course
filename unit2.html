1. Introduction and History of HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure web pages.

Features of HTML

  • Easy to learn and use.
  • Platform independent.
  • Supported by modern web browsers.
  • Works with CSS and JavaScript.
  • Supports text, links, tables, forms, audio and video.

History of HTML

YearDevelopment
1989Tim Berners-Lee proposed the World Wide Web.
1991HTML was introduced.
1995HTML 2.0 was developed.
1997HTML 3.2 became a recommendation.
1999HTML 4.01 was introduced.
2000XHTML 1.0 was introduced.
2014HTML5 became a recommendation.

2. HTML Document Structure and Elements

Every HTML document follows a basic structure containing a head section and a body section.

Basic HTML Structure

<!DOCTYPE html>
<html>
<head>
    <title>My First Page</title>
</head>
<body>
    <h1>Hello World</h1>
    <p>This is my first web page.</p>
</body>
</html>

Explanation of Tags

TagPurpose
<!DOCTYPE html>Declares HTML5.
<html>Root element.
<head>Contains page information.
<title>Sets the browser tab title.
<body>Contains visible webpage content.

HTML Elements and Tags

An HTML element generally consists of an opening tag, content and a closing tag.

<p>This is a paragraph.</p>
<h1>This is a heading.</h1>

Types of Elements

  • Paired elements: Have opening and closing tags, such as p and h1.
  • Empty elements: Do not contain content, such as br, hr and img.

Nested Elements

Elements placed inside other elements are called nested elements.

<html>
<body>
    <h1>My Heading</h1>
    <p>My paragraph.</p>
</body>
</html>

Important HTML Rules

  • Elements should be properly nested.
  • Close elements correctly whenever required.
  • HTML tags are not case-sensitive, but lowercase is recommended.
  • Do not skip closing tags where they are required.
Remember: The DOCTYPE declaration is written at the beginning of an HTML5 document.

3. Text, Formatting and Quotations

Headings

HTML provides six heading levels, from h1 to h6. H1 is the highest-level heading and h6 is the lowest.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

Paragraphs and Line Breaks

The p tag creates paragraphs, br creates a line break, and hr creates a horizontal separator.

<p>First paragraph.</p>
<p>Second paragraph.</p>

Hello<br>Welcome to HTML.

<hr>

Preformatted Text

The pre tag preserves spaces and line breaks.

<pre>
Name: Shrey
Course: B.Tech CSE
Year: First
</pre>

Text Formatting Tags

Quotations and Other Text Elements

4. Attributes, Colors and CSS

HTML Attributes

Attributes provide additional information about an element. They are written inside the opening tag.

<a href="https://www.google.com">Google</a>

<p style="color:blue;">Blue Text</p>

<img src="photo.jpg" alt="My Photo">

Common Attributes

AttributePurpose
hrefLink destination.
srcFile source.
altAlternative text.
width / heightElement dimensions.
idUnique identifier.
classGroups elements for styling.
styleInline CSS.
titleAdditional information.

Global attributes include id, class, style, title, lang, hidden and contenteditable. Boolean attributes such as required and disabled are enabled by their presence.

<input type="text" required>
<input type="text" disabled>

HTML Colors

Colors can be applied using CSS color properties.

<p style="color:red;">Red Text</p>

<p style="color:#0000FF;">Blue Text</p>

<p style="color:rgb(255,0,0);">Red Text</p>

<p style="color:rgba(0,0,255,0.5);">Blue Text</p>

<p style="color:hsl(240,100%,50%);">Blue Text</p>

HTML and CSS

CSS stands for Cascading Style Sheets. It controls the appearance and layout of HTML elements.

Three Ways to Apply CSS

1. Inline CSS: Written inside an element's style attribute.

<p style="color:blue;">Hello World</p>

2. Internal CSS: Written inside the style tag in the head.

<style>
p {
    color: blue;
    font-size: 20px;
}
</style>

3. External CSS: Written in a separate CSS file.

<link rel="stylesheet" href="style.css">

Example of the external CSS file:

body {
    background-color: white;
}

h1 {
    color: blue;
}

p {
    font-size: 18px;
}

5. HTML Links

Links connect one webpage to another. They are created using the anchor tag.

Basic Syntax and Example

<a href="https://www.google.com">
Visit Google
</a>

Target Attribute

ValuePurpose
_selfOpens in the same tab.
_blankOpens in a new tab.
_parentOpens in the parent frame.
_topOpens in the full window.
<a href="https://www.google.com"
   target="_blank">
Open Google in New Tab
</a>

Types of Links

Absolute URL: Contains the complete web address.

<a href="https://www.wikipedia.org">
Wikipedia
</a>

Relative URL: Points to a file relative to the current page.

<a href="about.html">About Us</a>

Email Link: Opens the user's email application.

<a href="mailto:student@example.com">
Send Email
</a>

Bookmark Link: Takes the user to a section on the same page.

<a href="#contact">Go to Contact</a>

<h2 id="contact">Contact Us</h2>

6. HTML Lists and Tables

HTML Lists

Lists are used to organize related information.

Unordered List

Displays items using bullet points.

<ul>
    <li>Coffee</li>
    <li>Tea</li>
    <li>Milk</li>
</ul>

Ordered List

Displays items using numbers or letters.

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

Different ordered list types can be selected using the type attribute.

<ol type="A">
    <li>Apple</li>
    <li>Banana</li>
</ol>

<ol type="i">
    <li>First</li>
    <li>Second</li>
</ol>

Description List

Displays terms along with their descriptions.

<dl>
    <dt>HTML</dt>
    <dd>Markup language for web pages.</dd>

    <dt>CSS</dt>
    <dd>Stylesheet language for web pages.</dd>
</dl>

Nested List

A list placed inside another list.

<ul>
    <li>Programming
        <ul>
            <li>Python</li>
            <li>C</li>
        </ul>
    </li>
</ul>

List Tags

TagPurpose
ulUnordered list.
olOrdered list.
liList item.
dlDescription list.
dtDescription term.
ddDescription details.

HTML Tables

Tables organize data in rows and columns.

TagPurpose
tableCreates a table.
trCreates a row.
thCreates a heading cell.
tdCreates a data cell.
captionAdds a table caption.
theadGroups header rows.
tbodyGroups main content rows.
tfootGroups footer rows.

Simple Table Example

<table border="1">
    <tr>
        <th>Name</th>
        <th>Course</th>
    </tr>
    <tr>
        <td>Shrey</td>
        <td>B.Tech CSE</td>
    </tr>
    <tr>
        <td>Aarav</td>
        <td>BCA</td>
    </tr>
</table>

Colspan and Rowspan

Colspan makes a cell occupy multiple columns.

<table border="1">
    <tr>
        <th colspan="2">Student Details</th>
    </tr>
    <tr>
        <td>Name</td>
        <td>Shrey</td>
    </tr>
</table>

Rowspan makes a cell occupy multiple rows.

<table border="1">
    <tr>
        <td rowspan="2">CSE</td>
        <td>HTML</td>
    </tr>
    <tr>
        <td>CSS</td>
    </tr>
</table>

Cell Padding and Spacing

Padding controls space inside cells, while border spacing controls the space between cells.

<table style="border-spacing:10px;">
    <tr>
        <td style="padding:10px;">HTML</td>
        <td style="padding:10px;">CSS</td>
    </tr>
</table>

Basic Syntax

Image Attributes

AttributePurpose
srcSpecifies the image location.
altProvides alternative text.
widthSets image width.
heightSets image height.

Image Example

<img src="flower.jpg"
     alt="A flower"
     width="300"
     height="200">

Common Image Formats

FormatUse
JPG / JPEGPhotographs.
PNGImages with transparency.
GIFSimple animations.
SVGScalable vector graphics.

ICOWebsite icons.

Image Map

An image map creates clickable areas within an image.

<img src="map.jpg" usemap="#mymap" alt="Map">

<map name="mymap">
    <area shape="rect"
          coords="0,0,100,100"
          href="page.html"

Picture Element

The picture element allows different image sources to be selected based on conditions such as screen size.

<picture>
    <source media="(max-width:600px)"
            srcset="small.jpg">
    <img src="large.jpg" alt="Example">
</picture>

Semantic elements clearly describe the meaning and purpose of the content they contain.

Advantages

  • Improve code readability.
  • Help search engines understand webpage content.
  • Improve accessibility.
  • Make websites easier to maintain.

Important Semantic Tags

TagPurpose
headerIntroductory content or page header.
navNavigation links.
mainMain webpage content.
sectionGroups related content.
articleIndependent content.
asideRelated side content.
footerFooter information.

Semantic HTML Example

<header>
    <h1>My Website</h1>
</header>

    <a href="index.html">Home</a>

    <section>

10. HTML5 Audio and Video

HTML5 provides audio and video elements that allow media to play directly in a browser without external plugins.

Video Element

<video width="400" controls>
    <source src="movie.mp4" type="video/mp4">
    Your browser does not support video.
</video>

Video Attributes

AttributePurpose
controlsDisplays playback controls.
autoplayRequests automatic playback.
loopRepeats the video.
mutedMutes the audio.
width / heightSets video dimensions.
posterSpecifies a preview image.

Audio Element

<audio controls>
    <source src="song.mp3" type="audio/mpeg">
    Your browser does not support audio.
</audio>

Audio also supports controls, autoplay, loop and muted. Multiple source elements can provide alternative file formats.

<audio controls>
    <source src="song.mp3" type="audio/mpeg">
    <source src="song.ogg" type="audio/ogg">
</audio>

11. Drag and Drop and XHTML

HTML5 Drag and Drop API

Drag and Drop allows users to move elements from one location to another using a supported input device.

Draggable Attribute

<div draggable="true">
    Drag Me
</div>

Important Events

EventPurpose
ondragstartRuns when dragging begins.
ondragoverRuns when an element is dragged over a target.
ondropRuns when an element is dropped.
ondragendRuns when dragging ends.

Drag and Drop Example

<!DOCTYPE html>
<html>
<body>

<div id="box" draggable="true"
     ondragstart="drag(event)">
    Drag Me
</div>

<div id="drop"
     ondragover="allowDrop(event)"
     ondrop="drop(event)">
    Drop Here
</div>

<script>
function allowDrop(event) {
    event.preventDefault();
}

function drag(event) {
    event.dataTransfer.setData("text", event.target.id);
}

function drop(event) {
    event.preventDefault();
    var data = event.dataTransfer.getData("text");
    event.target.appendChild(document.getElementById(data));
}
</script>

</body>
</html>

XHTML

XHTML stands for Extensible HyperText Markup Language. It is an XML-based version of HTML with stricter syntax rules.

Features of XHTML

  • Tags must be written in lowercase.
  • All elements must be properly closed.
  • Elements must be correctly nested.
  • Attribute values must be quoted.
  • Documents must follow XML syntax rules.

HTML vs XHTML

HTMLXHTML
Flexible syntax.Strict XML-based syntax.
Some end tags may be optional.Elements must be closed.
Uppercase tags are allowed.Lowercase tags are required.
Some attribute values may be unquoted.Attribute values must be quoted.

XHTML Example

<html xmlns="http://www.w3.org/1999/xhtml">
<head>
    <title>XHTML Page</title>
</head>
<body>
    <p>Hello World</p>
    <br />
</body>
</html>

12. HTML Meta Tags

Meta tags provide information about an HTML document. They are placed inside the head element and are not normally displayed on the webpage.

Common Meta Tags

Meta TagPurpose
charsetDefines character encoding.
viewportHelps pages adjust to screen sizes.
descriptionProvides a page summary.
authorSpecifies the page author.
refreshCan request automatic page refresh.

Meta Tag Example

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <meta name="description"
          content="HTML Learning Website">

    <meta name="author"
          content="Student">

    <title>My Website</title>

</head>

Important Meta Tags Explained

Charset: UTF-8 supports a wide range of characters.

Viewport: Helps webpages display correctly on mobile devices.

Description: Provides a short description of the webpage.
