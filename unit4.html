1. Introduction to Client-Side Scripting with JavaScript

What is JavaScript?

JavaScript is a high-level, dynamic programming language mainly used to make web pages interactive. It allows developers to respond to user actions, perform calculations, validate forms, change page content and communicate with servers.

JavaScript runs in modern web browsers and is one of the three main technologies of web development.

Technology Main Purpose
HTML Provides structure and content to a web page.
CSS Controls the appearance and design of a web page.
JavaScript Adds behaviour and interactivity to a web page.

Why is JavaScript Used?

  • To make web pages interactive.
  • To validate user input in forms.
  • To perform calculations.
  • To display messages and notifications.
  • To change HTML content dynamically.
  • To respond to mouse clicks and keyboard actions.
  • To communicate with servers and retrieve data.

Client-Side Scripting

Client-side scripting means that the script runs on the user's device, generally inside the web browser. JavaScript is commonly used for client-side scripting.

For example, when a student enters details in a registration form, JavaScript can check whether the required fields are filled before the form is submitted.

Basic JavaScript Example

<!DOCTYPE html>
<html>
<body>

<h2>My First JavaScript Program</h2>

<script>
    document.write("Welcome to JavaScript!");
</script>

</body>
</html>

The script element is used to write JavaScript code inside an HTML document. The document.write() method writes content into the document.

Ways to Add JavaScript to HTML

  1. Inline JavaScript: JavaScript is written directly inside an HTML element's event attribute.
  2. Internal JavaScript: JavaScript is written inside the script element in the HTML file.
  3. External JavaScript: JavaScript is written in a separate .js file and connected using the src attribute. 
<!-- Inline JavaScript -->
<button onclick="alert('Hello!')">
    Click Me
</button>

<!-- Internal JavaScript -->
<script>
    alert("Welcome!");
</script>

<!-- External JavaScript -->
<script src="script.js" defer></script>

The defer attribute makes an external script execute after the HTML document has been parsed.

2. JavaScript Variables and Data Types

What are Variables?

A variable is a named container used to store data. JavaScript variables can store information such as names, numbers, marks, results and other values.

Declaring Variables

JavaScript provides three commonly known declaration keywords:

Keyword Description
var Older way of declaring variables. It has function scope.
let Used when a variable's value may change.
const Used when a variable should not be reassigned. 
let name = "Shrey";
let marks = 85;

const college = "ITM SLS";

console.log(name);
console.log(marks);
console.log(college);

Rules for Naming Variables

  • A variable name can contain letters, numbers, underscore and dollar signs.
  • A variable name cannot begin with a number.
  • Spaces are not allowed in variable names.
  • JavaScript variable names are case-sensitive.
  • Reserved keywords cannot be used as variable names.

JavaScript Data Types

A data type describes the kind of value stored in a variable. JavaScript is dynamically typed, which means a variable can hold values of different types during program execution.

Data Type Example Meaning
String "Hello" Stores text.
Number 25, 10.5 Stores numeric values.
BigInt 123456789n Stores very large integers.
Boolean true, false Stores true or false values.
Undefined undefined A declared variable without an assigned value.
Null null Represents an intentional absence of value.
Symbol Symbol("id") Creates a unique value.
Object { name: "Asha" } Stores related properties and values.

Example of Different Data Types

const studentName = "Asha";
const marks = 85;
const isPass = true;

let course;

const result = null;

const subjects = ["HTML", "CSS", "JavaScript"];

const student = {
    name: "Asha",
    marks: 85
};

console.log(typeof studentName);
console.log(typeof marks);
console.log(typeof isPass);
console.log(typeof course);

Using typeof Operator

The typeof operator is used to find the type of a value or variable. 

let age = 20;
let name = "Asha";

console.log(typeof age);
console.log(typeof name);

Output:

number
string
Important: JavaScript returns "object" for typeof null because of a historical behaviour. Arrays also return "object". Use Array.isArray() to identify an array.

3. Operators, Conditions and Loops

JavaScript Operators

Operators are symbols used to perform operations on values and variables.

A. Arithmetic Operators

Operator Operation Example
+ Addition 10 + 5 = 15
- Subtraction 10 - 5 = 5
* Multiplication 10 * 5 = 50
/ Division 10 / 5 = 2
% Modulus (remainder) 10 % 3 = 1
** Exponentiation 2 ** 3 = 8

B. Assignment Operators

Operator Example Meaning
= x = 10 Assigns a value.
+= x += 5 Adds and assigns.
-= x -= 5 Subtracts and assigns.
*= x *= 2 Multiplies and assigns.
/= x /= 2 Divides and assigns.

C. Comparison Operators

Operator Meaning
==Equal value after type conversion.
===Equal value and equal type.
!=Not equal after type conversion.
!==Not equal value or type.
>Greater than.
<Less than.
>=Greater than or equal to.
<=Less than or equal to.

D. Logical Operators

Operator Name Purpose
&& AND True when both conditions are true.
|| OR True when at least one condition is true.
! NOT Reverses a Boolean value.

Conditional Statements

Conditional statements are used to make decisions in a program. They execute different blocks of code depending on whether a condition is true or false.

A. if Statement

Executes code when a condition is true.

let age = 20;

if (age >= 18) {
    console.log("Eligible to vote");
}

B. if-else Statement

Executes one block if the condition is true and another if it is false.

let marks = 75;

if (marks >= 40) {
    console.log("Pass");
} else {
    console.log("Fail");
}

C. else-if Statement

Checks multiple conditions one after another.

let marks = 85;

if (marks >= 90) {
    console.log("Grade A+");
} else if (marks >= 75) {
    console.log("Grade A");
} else if (marks >= 40) {
    console.log("Pass");
} else {
    console.log("Fail");
}

D. Ternary Operator

The ternary operator is a short way to write a simple if-else condition. 

let age = 20;

let result = (age >= 18) ? "Adult" : "Minor";

console.log(result);

Loops in JavaScript

Loops are used to execute a block of code repeatedly until a specified condition is met.

A. for Loop

A for loop is generally used when the number of repetitions is known. 

for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Output: 1 2 3 4 5

B. while Loop

A while loop repeats as long as its condition remains true. 

let i = 1;

while (i <= 5) {
    console.log(i);
    i++;
}

C. for...of Loop

The for...of loop is used to access values from iterable objects such as arrays. 

const subjects = ["HTML", "CSS", "JavaScript"];

for (const subject of subjects) {
    console.log(subject);
}

Example of Counting Items in an Array

const subjects = ["HTML", "CSS", "JavaScript", "PHP"];

let total = 0;

for (const subject of subjects) {
    total++;
}

console.log("Total subjects = " + total);

Output: Total subjects = 4

4. Functions and Popup Boxes

What are Functions?

A function is a reusable block of code designed to perform a particular task. Functions help reduce repetition and make programs easier to understand and maintain.

Function Syntax

function functionName() {
    // Statements
}

Example of a Simple Function

function greet() {
    console.log("Welcome to JavaScript!");
}

greet();

Output: Welcome to JavaScript!

Function Parameters and Arguments

Parameters are variables written in a function definition. Arguments are the actual values passed when calling the function. 

function greet(name) {
    console.log("Hello " + name);
}

greet("Shrey");

Output: Hello Shrey

Return Statement

The return statement sends a result back from a function. The returned value can be stored in a variable or used in another expression. 

function add(a, b) {
    return a + b;
}

let result = add(10, 20);

console.log(result);

Output: 30

Function to Calculate Total Price

function calculateTotal(price, quantity) {
    return price * quantity;
}

let bill = calculateTotal(120, 3);

console.log(bill);

Output: 360

JavaScript Popup Boxes

JavaScript provides built-in popup methods that allow a website to display messages, ask for confirmation or receive a short text response.

Method Purpose
alert() Displays a message with an OK button.
confirm() Displays OK and Cancel options.
prompt() Asks the user to enter a value.

A. alert() Method

alert("Welcome to Web Technologies!");

B. confirm() Method

let answer = confirm("Do you want to continue?");

if (answer) {
    console.log("You clicked OK");
} else {
    console.log("You clicked Cancel");
}

C. prompt() Method

let name = prompt("Enter your name:");

console.log("Hello " + name);
Note: Popup boxes are useful for simple examples and demonstrations. Professional websites generally use their own designed messages and forms for a better user experience.

5. JavaScript Objects and the DOM

What are JavaScript Objects?

An object is a collection of related data stored in the form of properties and methods. Properties describe an object, while methods define actions that the object can perform.

Example of an Object

const student = {
    name: "Asha",
    rollNo: 101,
    department: "Computer Science",

    displayInfo: function() {
        return this.name + " - " + this.department;
    }
};

console.log(student.name);
console.log(student.rollNo);
console.log(student.displayInfo());

In this example, name, rollNo and department are properties. The displayInfo() function is a method.

Accessing Object Properties

Object properties can be accessed in two common ways:

const student = {
    name: "Asha",
    age: 20
};

// Dot notation
console.log(student.name);

// Bracket notation
console.log(student["age"]);

What is DOM?

DOM stands for Document Object Model. It is a programming interface that represents an HTML document as a tree of objects called nodes.

JavaScript uses the DOM to access, change, add or remove HTML elements and their content.

How the DOM Works

  1. The browser reads the HTML document.
  2. The browser creates a DOM tree from the document.
  3. JavaScript selects elements from the DOM.
  4. JavaScript can modify content, attributes and styles.
  5. The browser displays the updated page.

Common DOM Selection Methods

Method Purpose
getElementById() Selects an element using its ID.
getElementsByClassName() Selects elements using their class name.
getElementsByTagName() Selects elements using their tag name.
querySelector() Selects the first element matching a CSS selector.
querySelectorAll() Selects all elements matching a CSS selector.

Changing HTML Content

<h2 id="heading">Old Heading</h2>

<script>
    document.getElementById("heading").textContent =
        "New Heading";
</script>

Changing CSS Using JavaScript

<p id="text">Hello Student</p>

<script>
    document.getElementById("text").style.color = "blue";
</script>

Changing Classes

The classList property allows JavaScript to add, remove, toggle or check CSS classes of an HTML element. 

document.querySelector(".box").classList.add("active");

document.querySelector(".box").classList.remove("active");

document.querySelector(".box").classList.toggle("active");

Creating and Adding New Elements

const newItem = document.createElement("li");

newItem.textContent = "JavaScript";

document.querySelector("#subjects").append(newItem);

The createElement() method creates a new HTML element. The append() method adds it to the selected parent element.

Remember: The DOM connects JavaScript with HTML. It allows web pages to update their content without rebuilding the entire document.

6. Forms and Form Validation

What is Form Validation?

Form validation is the process of checking user input before accepting or submitting it. It helps ensure that the entered information is complete and follows the required format.

Why is Form Validation Important?

  • Prevents empty or incomplete form submissions.
  • Checks whether the entered information is in the correct format.
  • Improves the user experience.
  • Reduces incorrect data sent to the server.
  • Helps applications collect accurate information.

HTML Form Validation Attributes

Attribute Purpose
required Makes a field compulsory.
type="email" Checks the basic format of an email address.
minlength Sets the minimum number of characters.
maxlength Sets the maximum number of characters.
min Sets the minimum allowed number or date.
max Sets the maximum allowed number or date.
step Sets the permitted interval between values.
pattern Checks input against a regular expression.

Example of HTML Validation

<form>

    Name:
    <input type="text" required minlength="2">

    Email:
    <input type="email" required>

    Age:
    <input type="number" min="18" max="60">

    <button type="submit">Submit</button>

</form>

JavaScript Form Validation

JavaScript can perform additional checks and display custom messages when a user enters incorrect information. 

function validateForm() {

    let name = document.getElementById("name").value;

    if (name == "") {
        alert("Please enter your name");
        return false;
    }

    alert("Form submitted successfully");
    return true;
}

Useful JavaScript Validation Methods

Method or Property Purpose
checkValidity() Checks whether the form or input satisfies its constraints.
reportValidity() Checks validity and asks the browser to show feedback.
validity Provides details about the validity state.
setCustomValidity() Sets a custom validation error message.

Form Validation Flow

  1. The user enters information into the form.
  2. The user clicks the submit button.
  3. The browser checks basic HTML validation rules.
  4. JavaScript performs additional validation if required.
  5. Error messages are displayed if the information is incorrect.
  6. Valid information can be sent to the server.
Important Security Point: Client-side validation is useful for user feedback, but it is not enough for security. A server must validate the submitted data again because browser-side checks can be bypassed.

7. Dynamic HTML (DHTML)

What is DHTML?

DHTML stands for Dynamic HTML. It is a combination of HTML, CSS and JavaScript used to create interactive web pages whose content and appearance can change while the page is open.

DHTML is not a separate programming language. It is a term used to describe how these three technologies work together.

Components of DHTML

Technology Role in DHTML
HTML Creates the structure and content of the page.
CSS Controls colours, layout and appearance.
JavaScript Changes content and responds to user actions.
DOM Allows JavaScript to access and modify page elements.

Features of DHTML

  • Dynamic changes to page content.
  • Interactive menus and buttons.
  • Changing styles without reloading the page.
  • Showing and hiding elements.
  • Responding to user actions.
  • Creating interactive effects and animations.

How DHTML Works

  1. HTML creates the elements of the web page.
  2. CSS applies styles to those elements.
  3. JavaScript detects user actions through events.
  4. JavaScript updates the DOM.
  5. The browser displays the updated content and styles.

Example of DHTML

HTML:

<div id="card" class="card">
    <h3>Interactive Course Card</h3>
    <p>Click the button to highlight this card.</p>
</div>

<button id="changeButton">Change Style</button>

CSS:

.card {
    padding: 15px;
    background-color: lightgray;
}

.card.active {
    background-color: teal;
    color: white;
}

JavaScript:

const card = document.getElementById("card");

const button = document.getElementById("changeButton");

button.addEventListener("click", function() {
    card.classList.toggle("active");
});

In this example, HTML creates the card, CSS defines its appearance and JavaScript changes its class when the button is clicked.

Good Practice: Keep the content in HTML, visual styling in CSS and interaction logic in JavaScript. This makes the code easier to understand and maintain.

8. JavaScript Events and Buttons

What are Events?

An event is an action or occurrence detected by the browser. JavaScript can respond to these events by executing a function.

For example, clicking a button, typing in a text box or submitting a form can generate events.

Common JavaScript Events

Event Description
click Occurs when an element is clicked or activated.
dblclick Occurs when an element is double-clicked.
mouseover Occurs when the pointer moves over an element.
mouseout Occurs when the pointer leaves an element.
keydown Occurs when a keyboard key is pressed.
keyup Occurs when a keyboard key is released.
input Occurs when the value of an input changes.
change Occurs when an input value is committed or changed.
submit Occurs when a form is submitted.
load Occurs when a resource or page finishes loading.

Event Handling

Event handling means writing JavaScript code that runs when a particular event occurs.

Using addEventListener()

The addEventListener() method is used to attach an event handler to an HTML element. 

document.getElementById("myButton")
    .addEventListener("click", function() {

        alert("Button clicked!");

    });

Understanding the Event Object

When an event occurs, the browser provides an event object containing information about that event. It can tell us which element received the event and what type of event occurred. 

button.addEventListener("click", function(event) {

    console.log("Event type:", event.type);

    console.log("Clicked element:", event.currentTarget);

});

Example of a Button Counter

let count = 0;

function increaseCount() {

    count++;

    document.getElementById("result").textContent = count;

}

Each time the button's event handler calls increaseCount(), the count increases by one.

Why Use addEventListener()?

  • It separates JavaScript from HTML structure.
  • It allows multiple listeners to be attached to an element.
  • It makes code easier to maintain.
  • It supports different types of browser events.

9. AJAX and Asynchronous Web Applications

What is AJAX?

AJAX stands for Asynchronous JavaScript and XML. It is a technique used to exchange data between a browser and a server without reloading the entire web page.

Although the name includes XML, modern AJAX applications commonly use JSON to exchange data.

Why is AJAX Used?

  • To update part of a web page without refreshing the whole page.
  • To retrieve information from a server.
  • To submit data in the background.
  • To create faster and more interactive websites.
  • To reduce unnecessary page reloads.

Examples of AJAX in Real Websites

  • Live search suggestions.
  • Refreshing messages in a chat application.
  • Checking whether a username is available.
  • Loading products without refreshing a shopping page.
  • Updating notifications.

How AJAX Works

  1. The user performs an action on a web page.
  2. JavaScript sends an HTTP request to a server.
  3. The server processes the request.
  4. The server sends a response, such as JSON or text.
  5. JavaScript reads the response.
  6. The required part of the web page is updated.

AJAX Request and Response Cycle

User Action
    |
    v
JavaScript Sends Request
    |
    v
Server Processes Request
    |
    v
Server Sends Response
    |
    v
JavaScript Reads Response
    |
    v
Web Page Updates Without Full Reload

What is Asynchronous Programming?

Asynchronous programming allows an operation, such as a network request, to continue without making the entire browser interface wait for it to finish.

JavaScript uses Promises and async/await to work with asynchronous operations.

What is Fetch API?

The Fetch API is a modern JavaScript feature used to send HTTP requests and receive responses from a server.

Example of Fetch API

async function loadData() {

    try {

        const response = await fetch("/api/courses");

        if (!response.ok) {
            throw new Error("Request failed");
        }

        const data = await response.json();

        console.log(data);

    } catch (error) {

        console.log("Error:", error);

    }

}

loadData();

Here, fetch() sends a request to the server. The response is checked, converted into JSON and displayed in the console. The example assumes that the server provides the /api/courses endpoint.

Important Fetch Concepts

  • fetch(): Sends a request to a URL.
  • Promise: Represents a result that may become available later.
  • async: Declares an asynchronous function.
  • await: Waits for a Promise inside an async function.
  • response.ok: Checks whether the HTTP response has a successful status.
  • response.json(): Reads and parses a JSON response body.
  • try...catch: Handles errors during the operation.

What is JSON?

JSON stands for JavaScript Object Notation. It is a lightweight data format commonly used to exchange information between a client and a server. 

{
    "name": "Asha",
    "age": 20,
    "course": "Computer Science"
}

Common HTTP Methods Used with AJAX

Method Purpose
GET Retrieves information from a server.
POST Sends information to a server.
PUT Replaces an existing resource.
DELETE Deletes a resource.

Cross-Origin Resource Sharing (CORS)

CORS stands for Cross-Origin Resource Sharing. It is a browser security mechanism that controls whether a web page can access resources from another origin.

If a website requests data from a different origin, the server must provide the appropriate CORS permission.

Important: AJAX is a communication technique, not a database or a server. The server must provide an endpoint that can process the request and return data.

10. Introduction to jQuery

What is jQuery?

jQuery is a JavaScript library designed to make common JavaScript tasks easier. It provides shorter methods for selecting HTML elements, handling events, changing content, creating effects and performing AJAX requests.

jQuery was especially useful when different browsers had different levels of JavaScript support. Modern browsers now provide many similar features directly, but jQuery is still found in many existing websites.

Features of jQuery

  • Simple HTML element selection.
  • Easy event handling.
  • DOM manipulation.
  • Animation and visual effects.
  • AJAX support.
  • Method chaining.

Basic jQuery Syntax

$(selector).action();

The dollar sign ($) is used as a shortcut for jQuery. The selector identifies the HTML element, and the action specifies what should happen to that element.

Including jQuery in an HTML Page

jQuery is a library, so it must be included in the project before its methods can be used. 

<script src="jquery.js"></script>

The file must exist at the specified path. Another option is to include jQuery through an official CDN.

Document Ready Function

The document ready function makes sure that the HTML document has been parsed before the jQuery code runs. 

$(document).ready(function() {

    console.log("Document is ready");

});

A shorter form is:

$(function() {

    console.log("Document is ready");

});

jQuery Selectors

Selector Purpose
$("p") Selects all paragraph elements.
$("#demo") Selects the element with ID demo.
$(".box") Selects elements with class box.
$("*") Selects all elements.
$("h1, p") Selects all h1 and paragraph elements.

jQuery Event Handling

The on() method is used to attach an event handler to selected elements. 

$(function() {

    $("#myButton").on("click", function() {

        alert("Button clicked!");

    });

});

Changing Text Using jQuery

$("#message").text("Hello Student!");

Adding and Removing Classes

// Add a class
$("#box").addClass("active");

// Remove a class
$("#box").removeClass("active");

// Toggle a class
$("#box").toggleClass("active");

jQuery Effects

jQuery provides methods for showing, hiding and animating selected elements.

Method Purpose
show() Displays a hidden element.
hide() Hides an element.
toggle() Switches between showing and hiding.
fadeIn() Displays an element with a fading effect.
fadeOut() Hides an element with a fading effect.
slideUp() Hides an element using a sliding effect.
slideDown() Displays an element using a sliding effect.
animate() Creates custom animations for supported CSS properties.

Example of jQuery Hide and Show

$(function() {

    $("#hideButton").on("click", function() {
        $("#message").hide();
    });

    $("#showButton").on("click", function() {
        $("#message").show();
    });

});

jQuery and Vanilla JavaScript Comparison

Vanilla JavaScript means using JavaScript directly without an additional library such as jQuery.

Task JavaScript jQuery
Select element document.querySelector("#message") $("#message")
Click event addEventListener("click", handler) .on("click", handler)
Change text element.textContent = "Hello" .text("Hello")
Toggle class classList.toggle("active") .toggleClass("active")
Remember: Learn JavaScript and DOM concepts first. jQuery becomes easier to understand once you know how JavaScript selects and modifies HTML elements.

11. JavaScript Debugging and Practical Applications

What is Debugging?

Debugging is the process of finding and correcting errors in a program. It helps developers understand why a program is not working as expected.

Common Types of Errors

Error Type Meaning
Syntax Error Occurs when code does not follow JavaScript syntax rules.
Reference Error Occurs when code refers to an unavailable variable or identifier.
Type Error Occurs when an operation is used with an unsuitable value or type.
Logical Error Program runs but produces an incorrect result.

Using console.log()

The console.log() method is used to display messages and variable values in the browser console. It is useful when checking whether a program is working correctly. 

let a = 10;
let b = 20;

let sum = a + b;

console.log("Sum = " + sum);

Browser Developer Tools

Modern browsers provide Developer Tools that help developers inspect HTML, CSS and JavaScript, view console messages, identify errors and debug programs.

In most desktop browsers, Developer Tools can be opened using F12 or Ctrl + Shift + I.

Practical Applications of JavaScript

  • Student registration and login forms.
  • Online shopping carts.
  • Interactive menus and navigation.
  • Calculators and result systems.
  • Form validation.
  • Live search and suggestions.
  • Interactive dashboards.
  • Dynamic content loading.

Small Practical Program: Student Result

let marks = 85;

if (marks >= 40) {
    console.log("Student Passed");
} else {
    console.log("Student Failed");
}

Small Practical Program: Display Array Values

const subjects = ["HTML", "CSS", "JavaScript"];

for (const subject of subjects) {
    console.log(subject);
}

Final Learning Point

JavaScript is responsible for the behaviour of a web page. It works with HTML, CSS, browser events and the DOM to create interactive websites. AJAX and Fetch help communicate with servers, while jQuery provides a shorter way to perform common JavaScript tasks.

Understanding variables, conditions, loops, functions, objects, events and DOM manipulation provides a strong foundation for learning advanced web development.
