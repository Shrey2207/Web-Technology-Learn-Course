1. Introduction to CSS

What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to control the appearance and presentation of HTML documents.

HTML provides the structure and content of a webpage, while CSS controls how that content looks. It is used to apply colours, fonts, spacing, borders, backgrounds and layouts to web pages.

Example:

HTML creates a heading, paragraph and button. CSS can change their colours, sizes, spacing and appearance.

Why is CSS Needed?

Without CSS, web pages mainly display content using the browser's default styles. CSS makes websites attractive, organised and easier to use.

  • Better Appearance: Adds colours, fonts, backgrounds and borders.
  • Separation of Content and Design: Keeps HTML structure separate from presentation.
  • Consistency: One stylesheet can give multiple pages the same design.
  • Responsive Design: Helps websites adjust to different screen sizes.
  • Less Repetition: Reusable CSS rules reduce repeated styling code.
  • Easy Maintenance: Changes can be made in one stylesheet instead of many HTML elements.

Separation of Content and Design

In a well-organised website, HTML is used for meaningful content and structure, while CSS is used for visual presentation.

HTML: 
Welcome to My Website


This is my first webpage.
CSS: 
h1 {
    color: blue;
    text-align: center;
}

p {
    font-size: 18px;
}

Same Content, Different Presentation

The same HTML content can be displayed in different ways by applying different CSS rules. The content remains unchanged, but its appearance can be modified.

Remember: HTML defines what appears on a page. CSS defines how that content is presented.

2. Types of CSS

CSS can be added to an HTML document in three main ways: Inline CSS, Internal CSS and External CSS.

1. Inline CSS

Inline CSS is written directly inside an HTML element using the style attribute. It applies styling to only that particular element.

  • Can cause repeated styling.

Internal CSS is written inside a style element in the head section of an HTML document. It is generally used when styling a single page.

3. CSS Syntax and Selectors

CSS Syntax

CSS syntax describes how styling rules are written. A CSS rule contains a selector and a declaration block.

Example: 
p {
    color: blue;
    font-size: 18px;
}
  • Selector: Selects the HTML element to style.
  • Property: Specifies what feature to change.
  • Value: Specifies how the property should appear.
  • Declaration: A property and its value together.

In the example, p is the selector, color and font-size are properties, and blue and 18px are their values.

1. Element Selector

An element selector selects all HTML elements of a particular type. 

p {
    color: red;
}

This rule applies to every paragraph.

2. Class Selector

A class selector selects elements that have a particular class attribute. It starts with a dot (.) in CSS. 

.note {
    background-color: yellow;
    padding: 10px;
}
HTML: 
This is a note.

3. ID Selector

An ID selector selects an element with a particular ID. It starts with a hash (#) symbol. 

#heading {
    color: blue;
    text-align: center;
}
HTML: 
My Website

4. Universal Selector

The universal selector uses an asterisk (*). It selects all elements on the page. 

* {
    box-sizing: border-box;
}

5. Grouping Selector

A grouping selector applies the same CSS rules to multiple selectors by separating them with commas. 

h1, h2, p {
    color: green;
}

6. Descendant Selector

A descendant selector selects elements located anywhere inside another specified element. 

nav a {
    text-decoration: none;
}

This selects all links inside a navigation element, including links inside nested elements.

7. Child Selector

A child selector selects only the direct children of a specified element. It uses the greater-than symbol (>). 

ul > li {
    color: blue;
}

8. Attribute Selector

An attribute selector selects HTML elements based on their attributes or attribute values. 

input[type="email"] {
    border: 2px solid blue;
}

9. Pseudo-class Selector

A pseudo-class selects an element when it is in a particular state or condition. 

a:hover {
    color: red;
}

button:active {
    background-color: green;
}

Common pseudo-classes include:

  • :hover – When the mouse pointer is over an element.
  • :active – While an element is being activated.
  • :focus – When an element receives keyboard or other focus.
  • :first-child – Selects an element that is the first child of its parent.
  • :last-child – Selects an element that is the last child of its parent.

10. Pseudo-element Selector

A pseudo-element styles a specific part of an element rather than selecting the whole element. 

p::first-line {
    font-weight: bold;
}

p::first-letter {
    color: red;
    font-size: 25px;
}

Difference Between Pseudo-class and Pseudo-element

Pseudo-class Pseudo-element
Selects an element based on its state or condition. Styles a specific part of an element.
Commonly uses one colon. Commonly uses two colons.
Example: :hover Example: ::first-line

4. CSS Values, Units and Custom Properties

CSS Values

A CSS property needs a valid value to work. Values can be colours, numbers, lengths, percentages, keywords or functions. 

h1 {
    color: blue;
    font-size: 25px;
    width: 80%;
}

CSS Units

CSS units are used to specify the size of text, width, height, spacing and other measurements.

Unit Meaning Example
px CSS pixel; a fixed reference unit. font-size: 16px;
em Relative to the computed font size of the element; for font-size, relative to its parent. padding: 2em;
rem Relative to the root element's font size. font-size: 1.5rem;
% Relative to a reference determined by the property. width: 80%;
vw One percent of viewport width. width: 50vw;
vh One percent of viewport height. height: 50vh;

Fixed and Relative Units

Fixed units such as px use a specific CSS measurement. Relative units such as %, em, rem, vw and vh depend on a reference size or the viewport.

Remember: Relative units are useful when creating flexible layouts and text that adapts to different screen sizes.

CSS Custom Properties (CSS Variables)

CSS custom properties are reusable values stored in variables. Their names begin with two hyphens and they are accessed using the var() function.

They help developers reuse colours, spacing, font sizes and other values throughout a website.

Example: 
:root {
    --main-color: blue;
    --space: 20px;
}

h1 {
    color: var(--main-color);
}

p {
    padding: var(--space);
}

Advantages of CSS Variables

  • Reduce repeated values.
  • Make stylesheets easier to maintain.
  • Allow common colours and spacing to be changed in one place.
  • Help maintain a consistent design.

5. CSS Cascade and Inheritance

What is the CSS Cascade?

The cascade is the process used by browsers to decide which CSS rule should apply when multiple rules target the same element and property.

The browser considers the origin and importance of rules, selector specificity and source order to determine the final style.

CSS Specificity

Specificity is the priority given to a selector based on the types of selectors it contains. A more specific selector generally overrides a less specific selector when other cascade conditions are equal.

Example: 
p {
    color: black;
}

.note {
    color: blue;
}

#warning {
    color: red;
}

The ID selector is more specific than the class selector, which is more specific than the element selector.

Specificity Order

Selector Type Example Priority
Element selector p Lower
Class selector .note Higher than element
ID selector #warning Higher than class
Inline style style="color: red" Usually higher than normal author stylesheet rules

The !important declaration can change the normal cascade priority, but it should be used carefully. 

p {
    color: red !important;
}

Source Order

When two rules have the same cascade priority and specificity, the rule that appears later in the stylesheet usually wins. 

p {
    color: red;
}

p {
    color: blue;
}

In this example, the paragraph will normally appear blue because the second rule comes later.

CSS Inheritance

Inheritance means that some CSS properties applied to a parent element can be passed down to its child elements when they do not have their own value. 

body {
    color: blue;
    font-family: Arial, sans-serif;
}

Paragraphs and other text elements can inherit the colour and font family from the body.

Inherited and Non-Inherited Properties

Inherited Properties Usually Non-Inherited Properties
color margin
font-family padding
font-size border
line-height width

Debugging CSS Errors

Sometimes CSS rules do not work as expected. Developers can use browser developer tools to inspect elements and find styling problems.

  • Check spelling of property names.
  • Check whether the value is valid.
  • Check opening and closing braces.
  • Check semicolons between declarations.
  • Check whether the correct stylesheet is linked.
  • Check whether another rule overrides the style.
Tip: Browsers generally ignore an invalid declaration and continue processing other valid declarations.

6. CSS Colours and Backgrounds

CSS Colours

CSS colours are used to change the appearance of text, backgrounds, borders and other elements. CSS supports different colour formats.

1. Named Colours

CSS provides predefined colour names that can be used directly. 

h1 {
    color: red;
}

p {
    color: blue;
}

body {
    background-color: lightyellow;
}

2. HEX Colours

HEX stands for hexadecimal. It represents colours using a hash symbol followed by hexadecimal digits. 

h1 {
    color: #FF0000;
}

p {
    color: #0000FF;
}

body {
    background-color: #F0F0F0;
}

3. RGB Colours

RGB stands for Red, Green and Blue. It combines these three colour components to create a colour. Each component normally ranges from 0 to 255. 

h1 {
    color: rgb(255, 0, 0);
}

p {
    color: rgb(0, 0, 255);
}

4. RGBA Colours

RGBA stands for Red, Green, Blue and Alpha. The alpha value controls the transparency of the colour itself. 

div {
    background-color: rgba(255, 0, 0, 0.5);
}

An alpha value of 0 is fully transparent, while 1 is fully opaque.

5. HSL Colours

HSL stands for Hue, Saturation and Lightness. Hue represents the colour angle, saturation represents colour intensity, and lightness represents how light or dark the colour is. 

h1 {
    color: hsl(0, 100%, 50%);
}

CSS Colour Formats

Format Example
Named Colour red
HEX #FF0000
RGB rgb(255, 0, 0)
RGBA rgba(255, 0, 0, 0.5)
HSL hsl(0, 100%, 50%)

Background Properties

Background properties control the appearance of the area behind an element's content.

1. Background Colour

The background-color property sets a solid background colour for an element. 

body {
    background-color: lightblue;
}

2. Background Image

The background-image property places an image or gradient behind an element's content. 

body {
    background-image: url("background.jpg");
}

3. Background Repeat

The background-repeat property controls whether a background image repeats.

  • repeat – Repeats in both directions.
  • repeat-x – Repeats horizontally.
  • repeat-y – Repeats vertically.
  • no-repeat – Does not repeat.
body {
    background-image: url("pattern.png");
    background-repeat: no-repeat;
}

4. Background Position

The background-position property controls where the background image is placed. 

body {
    background-position: center;
}

Other possible values include:

  • left top
  • right top
  • center center
  • left bottom
  • right bottom

5. Background Size

The background-size property controls the dimensions of a background image.

  • cover: Scales the image to cover the entire area, possibly cropping it.
  • contain: Scales the image so the whole image fits inside the area.
  • auto: Uses the image's natural size or a size based on other dimensions.
.banner {
    background-image: url("banner.jpg");
    background-size: cover;
    background-position: center;
}

6. Background Attachment

The background-attachment property controls how a background image behaves while scrolling.

  • scroll – Background scrolls with the element.
  • fixed – Background is fixed relative to the viewport.
  • local – Background scrolls with the element's content.
body {
    background-image: url("background.jpg");
    background-attachment: fixed;
}

7. CSS Gradients

A gradient creates a smooth transition between two or more colours. Gradients are treated as CSS-generated background images.

Linear Gradient

A linear gradient changes colours along a straight line in a specified direction. 

.banner {
    background-image: linear-gradient(
        to right,
        blue,
        green
    );
}

Radial Gradient

A radial gradient spreads colours outward from a central point. 

.box {
    background-image: radial-gradient(
        red,
        yellow,
        green
    );
}
Good Practice: Always choose background and text colours with sufficient contrast so that website content remains readable.

7. Text and Font Properties

Introduction

CSS text and font properties control how text appears on a webpage. They are used to improve readability and organise information.

1. Font Family

The font-family property specifies the typeface used for text. It is good practice to provide fallback fonts. 

p {
    font-family: Arial, sans-serif;
}

2. Font Size

The font-size property controls the size of the text. 

h1 {
    font-size: 30px;
}

p {
    font-size: 18px;
}

3. Font Weight

The font-weight property controls how thick or bold the text appears. 

h1 {
    font-weight: bold;
}

p {
    font-weight: normal;
}

Numeric values such as 400 and 700 can also be used when supported by the selected font.

4. Text Alignment

The text-align property controls the horizontal alignment of text inside an element. 

h1 {
    text-align: center;
}

p {
    text-align: justify;
}

Common values:

  • left – Aligns text to the left.
  • right – Aligns text to the right.
  • center – Aligns text to the centre.
  • justify – Adjusts spacing so lines align along both edges.

5. Line Height

The line-height property controls the vertical space between lines of text. 

p {
    line-height: 1.6;
}

6. Text Decoration

The text-decoration property adds or removes decorative lines from text. 

h1 {
    text-decoration: underline;
}

a {
    text-decoration: none;
}

Common values:

  • underline – Adds a line below text.
  • overline – Adds a line above text.
  • line-through – Adds a line through text.
  • none – Removes text decoration.

7. Text Transform

The text-transform property changes the visual letter case of text without changing the original HTML content. 

h1 {
    text-transform: uppercase;
}

p {
    text-transform: capitalize;
}

Common values:

  • uppercase – Displays all letters in uppercase.
  • lowercase – Displays all letters in lowercase.
  • capitalize – Displays the first letter of each word in uppercase.
  • none – Uses the original text case.

Common Font and Text Properties

Property Purpose
font-family Changes the typeface.
font-size Changes text size.
font-weight Changes text thickness.
text-align Controls horizontal alignment.
line-height Controls vertical spacing between lines.
text-decoration Adds or removes text decoration.
text-transform Changes the displayed letter case.

8. CSS Borders and Box Model

CSS Borders

Borders are used to create an outline around HTML elements. They can be used around paragraphs, images, buttons and containers.

Border Width

The border-width property controls the thickness of a border. 

div {
    border-width: 3px;
}

Border Style

The border-style property specifies the appearance of a border.

  • solid – A continuous line.
  • dotted – A dotted line.
  • dashed – A dashed line.
  • double – Two parallel lines.
  • none – No border.
.box1 {
    border-style: solid;
}

.box2 {
    border-style: dashed;
}

.box3 {
    border-style: dotted;
}

Border Colour

The border-color property sets the colour of an element's border. 

div {
    border-color: blue;
}

Border Shorthand

The border shorthand property can set border width, style and colour together. 

div {
    border: 3px solid blue;
}

Border Radius

The border-radius property creates rounded corners on an element. 

button {
    border-radius: 10px;
}

CSS Box Model

The CSS box model describes how every HTML element is represented as a rectangular box. It consists of four main parts: content, padding, border and margin.

Parts of the Box Model

  1. Content: The actual text, image or other information inside the element.
  2. Padding: The space between the content and the border.
  3. Border: The line surrounding the padding and content.
  4. Margin: The outside space separating the element from neighbouring elements.
Box Model Example: 
div {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
}

Content-box

The default value of box-sizing is content-box. With content-box, the declared width applies only to the content. Padding and borders are added to the total rendered width.

Example: 
div {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    box-sizing: content-box;
}

Total width = 300 + 40 + 10 = 350px. The horizontal margins are added outside this.

Border-box

With border-box, the declared width includes the content, padding and border. This makes element sizing easier to calculate. 

div {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    box-sizing: border-box;
}

The total width remains 300px. The content area becomes smaller to make room for padding and borders.

Applying Border-box to All Elements

*, *::before, *::after {
    box-sizing: border-box;
}

Content-box vs. Border-box

Content-box Border-box
Width applies to content only. Width includes content, padding and border.
Padding and border increase the rendered width. Padding and border fit inside the declared width.
Default CSS box sizing. Often used for predictable layouts.

Margin Collapsing

In normal block layout, vertical margins of neighbouring block elements can sometimes collapse into one margin instead of being added together. This behaviour is called margin collapsing.

Remember: Padding is inside the border, while margin is outside the border.

9. CSS Positioning

Introduction to Positioning

CSS positioning controls how HTML elements are placed on a webpage. The position property determines how an element is positioned.

CSS provides five commonly used positioning values: static, relative, absolute, fixed and sticky.

1. Static Positioning

Static is the default position of HTML elements. The element appears in the normal document flow. Top, right, bottom and left offsets do not move a statically positioned element. 

div {
    position: static;
}

2. Relative Positioning

Relative positioning moves an element from its original position. Its original space remains reserved in the document flow. 

div {
    position: relative;
    top: 20px;
    left: 30px;
}

3. Absolute Positioning

Absolute positioning removes an element from normal document flow. It is positioned relative to its nearest positioned ancestor. If no such ancestor exists, its containing block is usually the initial containing block. 

.parent {
    position: relative;
}

.child {
    position: absolute;
    top: 10px;
    right: 10px;
}

4. Fixed Positioning

Fixed positioning places an element relative to the viewport. It usually stays in the same position even when the page is scrolled. 

button {
    position: fixed;
    bottom: 20px;
    right: 20px;
}

5. Sticky Positioning

Sticky positioning behaves like relative positioning until a specified scrolling threshold is reached. It then sticks within its scrolling container. 

h2 {
    position: sticky;
    top: 0;
}

Positioning Properties

Property Purpose
top Sets the distance from the top edge of the containing reference.
right Sets the distance from the right edge.
bottom Sets the distance from the bottom edge.
left Sets the distance from the left edge.
z-index Controls stacking order within the relevant stacking context.

Difference Between Position Values

Position Behaviour
Static Default position in normal flow.
Relative Moves from its original position and keeps its space.
Absolute Leaves normal flow and uses a positioned containing block.
Fixed Usually stays positioned relative to the viewport.
Sticky Moves normally until a scroll threshold is reached.
Important: A common use of relative positioning is to create a reference box for an absolutely positioned child element.

10. CSS3 and Modern CSS Features

What is CSS3?

CSS3 is a commonly used classroom term for modern CSS features introduced through different CSS modules. Modern CSS is developed as separate specifications such as Selectors, Grid, Colours and Media Queries.

CSS helps developers create attractive, flexible, responsive and interactive website layouts.

Normal Document Flow

Normal document flow is the default arrangement of elements on a webpage. Block elements generally appear one below another, while inline elements appear within the same line when space is available. 

First Box


Second Box


Third Element

Flexbox

Flexbox, also called Flexible Box Layout, is a CSS layout system used to arrange elements in a row or column. It is useful for navigation menus, buttons and groups of items.

Flexbox makes it easier to align and distribute space between elements.

Important Flexbox Properties

  • display: flex: Creates a flex container.
  • flex-direction: Sets the main direction of items.
  • justify-content: Controls distribution along the main axis.
  • align-items: Aligns items along the cross axis.
  • flex-wrap: Allows items to move onto another line.
  • gap: Sets spacing between items.
Example: 
.container {
    display: flex;
    flex-direction: row;
    justify-content: center;
    align-items: center;
    gap: 20px;
}

CSS Grid

CSS Grid is a two-dimensional layout system. It allows developers to arrange elements in rows and columns.

Grid is useful for creating card layouts, galleries and complete website structures.

Important Grid Properties

  • display: grid: Creates a grid container.
  • grid-template-columns: Defines the columns.
  • grid-template-rows: Defines the rows.
  • gap: Sets spacing between grid items.
  • grid-column: Controls how an item spans columns.
  • grid-row: Controls how an item spans rows.
Example: 
.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 15px;
}

Flexbox vs. Grid

Flexbox CSS Grid
Mainly one-dimensional layout. Two-dimensional layout.
Arranges items in a row or column. Arranges items in rows and columns.
Useful for navigation bars and aligned items. Useful for page layouts and card grids.

Rounded Corners

The border-radius property is used to create rounded corners on elements. 

.box {
    border: 2px solid blue;
    border-radius: 12px;
}

Box Shadow

The box-shadow property adds a shadow effect around an element. It can create depth and visual separation. 

.card {
    box-shadow: 0 4px 10px gray;
}

Linear Gradient

A linear gradient creates a smooth colour transition along a straight line. 

.box {
    background: linear-gradient(
        to right,
        blue,
        green
    );
}

CSS Transform

The transform property changes the position, size, rotation or shape of an element without changing the normal document flow.

Common transform functions include:

  • translate() – Moves an element.
  • rotate() – Rotates an element.
  • scale() – Changes the size of an element.
  • skew() – Slants an element.
.box:hover {
    transform: scale(1.1);
}

CSS Transition

The transition property creates a smooth change between the old and new values of a CSS property. It is commonly used with hover effects. 

button {
    background-color: blue;
    transition: background-color 0.3s;
}

button:hover {
    background-color: green;
}

CSS Media Queries

Media queries allow CSS rules to be applied only when certain conditions are true, such as the width of the browser window.

They are an important part of responsive web design.

Example: 
@media (max-width: 600px) {
    .container {
        width: 100%;
    }

    h1 {
        font-size: 22px;
    }
}

Responsive Layouts

A responsive layout adjusts to different screen sizes such as mobile phones, tablets and desktops. It uses flexible widths, layout systems and media queries.

Using CSS Grid for Responsive Layout

.feature-list {
    display: grid;
    grid-template-columns:
        repeat(auto-fit, minmax(180px, 1fr));
    gap: 14px;
}

The auto-fit and minmax() functions help the grid adapt its columns according to the available space.

Reduced Motion Preference

Some users prefer less animation and movement on websites. CSS provides the prefers-reduced-motion media feature to respect this preference. 

@media (prefers-reduced-motion: reduce) {
    .box {
        transition: none;
        transform: none;
    }
}

Choosing the Right Layout Method

Layout Method Best Use
Normal Flow Regular paragraphs and block content.
Flexbox Navigation bars, rows and columns of aligned items.
Grid Layouts requiring rows and columns together.
Media Queries Changing layouts for different screen conditions.
Important: Flexbox and Grid can be used together. Choose the layout method according to the structure of the content.
